# CYBERSEC RANGE 本地前端重写版

独立、零依赖的前端实现。未复用参考设计站或旧演示项目的页面组件代码；态势感知视图使用用户提供的 1920×1080 页面素材进行本地集成。

## 本地运行

```bash
npm run dev
```

默认地址：`http://127.0.0.1:7180/`

## 当前范围

- 态势感知页面已接入实时攻防态势总览
- 大屏内容在右侧工作区内保持 16:9 比例并等比缩放，避免裁切和图形变形
- 态势感知页侧栏固定为 64px 收起态
- 其他页面侧栏固定为 240px 展开态
- 不提供手动展开或收起入口
- 全站不使用顶栏
- 其他页面暂时使用占位内容，等待逐页梳理
